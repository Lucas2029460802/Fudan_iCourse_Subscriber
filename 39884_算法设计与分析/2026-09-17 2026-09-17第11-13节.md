### 快速排序时间复杂度分析
快速排序的核心在于“划分”操作。通过选择一个枢纽元，将数组划分为左右两个子数组，使得左侧所有元素均小于枢纽元，右侧所有元素均大于枢纽元。由于每次划分都需要遍历当前区间的所有元素，其子算法 `Partition` 的复杂度为 $\Theta(n)$。

**最坏情况分析**
当输入数组已处于正序或逆序，且每次均选取当前数组中的最小或最大元素作为枢纽元时，划分操作会极不平衡。此时，一侧的子数组为空，另一侧的子数组规模为 $n-1$。该情况的递归式可表示为 $T(n) = T(n-1) + \Theta(n)$。展开此递归树，会发现它退化成一条链，每层代价分别为 $cn, c(n-1), …, c$。将这些代价求和，得到 $c \cdot \frac{n(n+1)}{2} + \Theta(1)$，因此最坏情况下的时间复杂度为 $\Theta(n^2)$。

**平均情况分析**
平均情况下，我们假设所有输入排列是等概率的。枢纽元可能落在排好序的 $1$ 到 $n$ 的任意一个位置，且每种位置导致的两个子问题规模各不相同。将所有 $n$ 种可能的递归情况求和并取平均，可以得到如下递归式：
$$T(n) = \frac{2}{n} \sum_{i=1}^{n-1} T(i) + \Theta(n)$$
该递归式包含一个求和项，难以直接使用递归树求解。我们采用一种代数技巧：将该等式两边同时乘以 $n$，并写出 $n-1$ 时的对应等式，然后将两式相减，以消去求和符号。通过一系列化简，可得到一个关于 $\frac{T(n)}{n+1}$ 的递推关系，最终求解得出平均时间复杂度为 $\Theta(n \log n)$。这说明，尽管快速排序在最坏情况下性能不佳，但其在平均情况下表现非常高效。

### 分治算法思想
归并排序与快速排序的共同点并非仅仅是“将问题变小”，而是它们能将原问题拆分为结构与原问题完全相同的子问题，并递归求解。这正是分治算法的核心思想。

**基本流程**
分治算法通常包含三个步骤：
1.  **分解**：将一个复杂的大问题，划分成若干个规模更小、形式相同的子问题。
2.  **解决**：递归地求解每一个子问题。当子问题规模足够小时，直接求解。
3.  **合并**：将各个子问题的解组合起来，形成原问题的最终解。

**关键特征**
判断一个算法是否为分治算法，需要检查几个关键点：子问题的规模是否比原问题小；子问题是否保持了与原问题相同的结构；子问题的解如何被合并；以及递归的边界条件是什么。

**递归与分治的区别**
需要注意的是，递归是一种实现技术，而分治是一种算法设计思想。使用递归不一定就是分治算法。例如，计算阶乘 $n! = n \times (n-1)!$ 虽然可以用递归实现，但它只产生一个规模为 $n-1$ 的子问题，并未通过分解来降低整体复杂度。典型的分治算法，如快速排序，会产生多个结构相同的子问题，并籍此实现效率上的提升。

**分与合的复杂度侧重**
同为分治算法，不同算法的设计难点可能落在不同阶段。快速排序的设计难点在于**分解**阶段，它必须设计出高效的 `Partition` 方法。而归并排序的设计难点在于**合并**阶段，它需要高效的 `Merge` 操作将两个有序子数组合并为一个。分治并非简单地一概而论，其效率取决于拆分的形态、子问题的数量与大小，以及分、合过程自身的开销。

### 比较排序算法的下界
我们学习了多种排序算法，它们在最坏情况下的最好时间复杂度是 $\Theta(n \log n)$。一个自然的问题是：能否设计出比 $n \log n$ 更快的比较排序算法？答案是否定的。我们可以通过决策树模型来证明这一点。

**决策树模型**
一个比较排序算法可以抽象为一棵决策树。树中的每个内部节点代表一次两个元素间的比较，其左右分支分别代表比较结果。算法的执行过程就是从树根到某个叶子结点的路径，而叶子结点则代表了输入数据的一种可能排序结果。
-   对于 $n$ 个互不相同的元素，总共有 $n!$ 种可能的排列。因此，任何能够正确排序的决策树都必须拥有至少 $n!$ 个叶子结点。
-   算法的最坏情况运行时间，对应着决策树的高度 $h$。
-   对于一棵高度为 $h$ 的二叉树，其叶子结点最多为 $2^h$ 个。

**下界证明**
结合以上三点，我们有 $n! \le 2^h$。对该不等式两边取对数，得到 $h \ge \log(n!)$。利用斯特林公式近似阶乘， $\log(n!) \approx n \log n - n \log e$。因此，我们可以得出结论：$h = \Omega(n \log n)$。这意味着，在最坏情况下，任何基于比较的排序算法，其比较次数都不可能少于 $n \log n$ 的量级。这个下界成立的前提是算法仅通过比较来获取元素间的顺序信息，并需处理所有可能的任意输入排列。

**非比较排序**
如果要突破 $\Omega(n \log n)$ 的界限，就不能依赖两两比较。例如，计数排序直接利用了元素键值的范围约束，通过统计每个键值出现的频率来实现排序。当待排序数据的范围 $k$ 是有限且已知的时候，其时间复杂度可以达到 $O(n+k)$。这揭示了算法设计中的一个重要哲学：上界（我们能做多好）提供可能性，下界（问题本身的难度极限）揭示边界。要突破性能极限，往往需要引入新的假设或操作。

### 递归式求解方法
分析分治算法的复杂度常会得到递归式。求解递归式有几种常用的方法。

**递归树法**
将递归式一层层展开，用树状结构来表示，每一层代表一次递归调用的代价，将所有层的代价求和即可。此方法直观，例如求解 $T(n) = T(n-1) + \Theta(n)$，其递归树是一条链，求和得 $\Theta(n^2)$。

**代入法**
直接反复代入递归式，直至触及边界条件。例如，对于 $T(n)=T(n-1)+n-1$，可将其展开为 $T(1) + 1 + 2 + … + (n-1)$，从而求得结果为 $n(n-1)/2$。对于形式更复杂的，如 $T(n) = 2T(n/2) + n - 1$，可设 $n = 2^k$ 进行换元代入，最终解为 $\Theta(n \log n)$。

**假设验证法（先猜后证）**
这是一种策略性方法，适用于递归式结构复杂、难以直接求解的情况。其核心步骤如下：
1.  **先猜**：根据经验或直觉，猜测递归式 $T(n)$ 的解，例如猜测其复杂度为 $O(n \log n)$，即假设 $T(n) \le c \cdot n \log n$。
2.  **代入验证**：将猜测的界代入原递归式，检验不等式是否成立。
3.  **校验规则（“三看”）**：
    -   **看阶**：代回后，主导增长阶是否一致。
    -   **看系数**：若最高阶一致，检查最高阶项的系数是否能自洽，以充分大的 $n$ 满足不等关系。
    -   **看低阶项**：如果仅为判断渐近阶，严格低阶项可以忽略，因为高阶项的增长会主导低阶项。

**主定理（Master Theorem）**
对于形如 $T(n) = aT(n/b) + f(n)$ 的递归式，主定理提供了一套快速求解的“套公式”方法。其中 $a \ge 1, b > 1$ 为常数，$f(n)$ 是一个函数。
-   **情况1**：若 $f(n) = O(n^{\log_b a - \epsilon})$，对某个常数 $\epsilon > 0$，则 $T(n) = \Theta(n^{\log_b a})$。
-   **情况2**：若 $f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$。
-   **情况3**：若 $f(n) = \Omega(n^{\log_b a + \epsilon})$，对某个常数 $\epsilon > 0$，且对某个常数 $c<1$ 和所有充分大的 $n$ 满足 $af(n/b) \le cf(n)$，则 $T(n) = \Theta(f(n))$。

主定理本质上是递归树法的数学总结。它通过比较非递归开销 $f(n)$ 与 $n^{\log_b a}$ 的渐近大小关系来决定复杂度量级。但主定理有其局限性，例如 $T(n) = 2T(n/2) + n \log n$ 就无法用主定理求解，因为 $n \log n$ 与 $n$ 的差距不是多项式量级的。此时必须回归到递归树或代入法。

### 二分检索算法
这是一个在已排序数组中查找特定元素的高效算法。它将分治思想发挥到极致，但操作上简化为“分”而无需“合”。

**算法过程**
每次将待查找元素 $x$ 与当前搜索区间的中间元素 $T[m]$ 比较：
-   若相等，则查找成功。
-   若 $x < T[m]$，则问题规模减半，转去左半区间继续查找。
-   若 $x > T[m]$，则问题规模减半，转去右半区间继续查找。

**复杂度分析**
-   **最坏情况**：每次比较后，搜索范围都缩小一半，直到区间大小为1。因此，最坏情况下的比较次数为 $\Theta(\log n)$。
-   **平均情况**：假设查找 $x$ 在数组中和不在数组中的 $2n+1$ 种情况等概率。通过构建决策树并计算加权平均路径长度，同样可以证明平均情况下的时间复杂度也是 $\Theta(\log n)$。例如，在一次查找中，规模为1的子问题（即一次比较就找到）有 $2^0$ 个，规模为2的有 $2^1$ 个，以此类推。将所有情况的比较次数累加求平均，结果约等于 $\log n$ 的量级。

### 分治算法的应用：Strassen矩阵乘法
矩阵乘法是许多科学计算与AI应用的基础运算。对于 $n \times n$ 的方阵 $A$ 和 $B$，计算其乘积 $C=AB$ 的标准算法包含三重循环，时间复杂度为 $\Theta(n^3)$。

**分块尝试与瓶颈**
初看之下，一个直接的分治策略是将每个矩阵分成四个 $n/2 \times n/2$ 的子块。计算所有子块需要 **8次** $n/2$ 规模矩阵乘法和 **4次** 矩阵加法。其递归式为 $T(n) = 8T(n/2) + \Theta(n^2)$。根据主定理（情况1），此解法的时间复杂度仍为 $\Theta(n^3)$，并无改进。瓶颈在于递归式的核心——子问题个数 $a=8$。

**Strassen算法的核心思想：以加法换乘法**
Strassen算法通过巧妙地构造7个中间矩阵的“混合乘法”，用额外的矩阵加减法运算，成功地将一次递归乘法替换掉。它的思路是：我们并不需要独立地计算出 `ae`, `bg`, `ah` 等每一个子块乘积，我们需要的只是它们的特定线性组合，如 $r = ae + bg$。通过精心设计的 $M_1$ 到 $M_7$ 这7次乘法组合（例如 $M_1 = (a+d)(e+h)$），可以在完成乘法后，通过加减法消去不必要的项，组合出最终需要的 $r, s, t, u$ 四个子块。

**算法复杂度提升**
由于将8次乘法减少到 **7次**，算法递归式变为 $T(n) = 7T(n/2) + \Theta(n^2)$。此时 $a=7, b=2$，层叠复杂度为 $n^{\log_2 7} \approx n^{2.807}$。根据主定理（情况1），$T(n) = \Theta(n^{2.807})$。这虽然只是渐近意义上的优化，但首次证明了 $n^3$ 的壁垒可以被算法思想打破。

**算法优化并非唯一路径**
渐近复杂度的降低不等于绝对运行速度的必然提升。在现代AI计算中，矩阵乘法的性能还深度依赖于**数据的本地性**和**硬件特性**。例如，通过**分块**技术将大矩阵切分为适配高速缓存大小的块进行计算，可以最大化数据复用，减少昂贵的内存搬运开销。进一步地，这种思想发展为 **Tile-based 计算**，继而催生了 **GEMM** 这样的高度优化的算子库。它结合了分块、向量化、并行计算等技术，是BLAS规范在现代硬件上的极致实现。像 `FlashAttention` 这样的前沿工作，其核心正是通过重新组织计算（如按Tile分块），使中间结果驻留在GPU的高速SRAM中，从而减少数据IO，而非单纯降低理论计算量FLOPs。

### 分治算法的应用：多项式乘法与卷积
向量卷积 $c_k = \sum_{i+j=k} a_i b_j$ 与多项式乘法在计算上是等价的。对于两个 $n$ 阶多项式，暴力计算其系数卷积的复杂度是 $\Theta(n^2)$。

**Karatsuba算法**
类似于Strassen算法的思想，Karatsuba算法同样通过“加（减）法换乘法”来优化。直接对多项式进行奇偶分治会产生4次 $n/2$ 规模的子问题乘法，其复杂度依然是 $\Theta(n^2)$。Karatsuba算法注意到，中间项 $A_0 B_1 + A_1 B_0$ 可以用一次乘法 $(A_0 + A_1)(B_0 + B_1)$ 减去另外两个已经计算出的乘积 $A_1 B_1$ 和 $A_0 B_0$ 来得到。这样，总的乘法次数就从 **4次减少为3次**。其递归式为 $T(n) = 3T(n/2) + O(n)$，用主定理（情况1）求解得 $T(n) = \Theta(n^{\log_2 3}) \approx \Theta(n^{1.585})$，实现了比暴力法更优的渐近复杂度。

**走向线性对数阶：快速傅里叶变换（FFT）思想**
能否进一步优化到 $n \log n$ 级别？这需要完全转换思路，利用多项式的“点值表示法”。一个 $n-1$ 次多项式可以由其在 $n$ 个不同点上的取值唯一确定。如果有了点值表示，两个多项式的乘法和加法将变得异常简单：只需对相应点上的值进行逐点相乘（$O(n)$ 复杂度）或相加即可。问题的难点和优化的焦点就转换到了两个过程：**求值**（从系数表示到点值表示）和**插值**（从点值表示回到系数表示）。显然，如果求值和插值的过程本身就是 $\Theta(n^2)$，那便毫无意义。

**FFT的核心思想：选择巧妙的求值点**
FFT通过分治策略加速求值和插值过程。其关键在于**精心选择求值点**，使得递归过程中的计算可以大量复用。
1.  **构造正负对**：将多项式 $A(x)$ 拆分为偶次项 $A_{even}(x^2)$ 和奇次项 $x A_{odd}(x^2)$。此时，计算一个点 $x$ 和 $-x$ 的函数值时，$A_{even}(x^2)$ 和 $A_{odd}(x^2)$ 的值是完全相同的，可以复用。这立刻将 $n$ 个点的求值问题，转化为在两个 $n/2$ 规模的子多项式上各求 $n/2$ 个点的问题。
2.  **递归性要求与单位复数根**：为了让这个“折半复用”的过程能递归地进行下去，需要保证选出的 $n$ 个点 ${\pm x_0, …, \pm x_{n/2-1}}$，在平方之后，剩下的 $n/2$ 个点 ${x_0^2, …, x_{n/2-1}^2}$ 本身又是一组正负对。**$n$ 次单位复数根** $\omega_n = e^{2\pi i / n}$ 完美地满足这个性质。根据折半定理，$\omega_n^k$ 和 $\omega_n^{k+n/2}$ 总是互为相反数，且这 $n$ 个根的平方恰好是 $n/2$ 个 $n/2$ 次单位复数根。

基于此，FFT的递归式变为 $T(n) = 2T(n/2) + \Theta(n)$，解得 $T(n) = \Theta(n \log n)$。这个 $\Theta(n)$ 来自于合并阶段，即利用复用的子问题结果计算正负两个点的值。逆傅里叶变换（插值）与FFT形式几乎一致，同样可在 $\Theta(n \log n)$ 时间内完成。因此，多项式的点值相乘与FFT/逆FFT结合，将卷积计算的复杂度整体降低到了 $\Theta(n \log n)$。该算法在密码学、大整数乘法、信号处理等领域有深远影响。
