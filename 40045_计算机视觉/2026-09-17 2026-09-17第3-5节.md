### 神经网络基础

我们从线性分类器最基本的数学形式开始回顾。给定一个输入向量 $x \in \mathbb{R}^D$ 和一个可学习的权重矩阵 $W \in \mathbb{R}^{C \times D}$，线性分类器的输出可以表示为 $f = Wx$。这一操作将 $D$ 维的输入映射到一个 $C$ 维的输出空间，以完成例如 $C$ 类的分类任务。但这仅仅是一个线性映射，其表达能力非常有限。

为了增强模型的表达能力，我们引入了神经网络。一个最简单的两层神经网络可以表示为 $f = W_2 \max(0, W_1 x)$。这里，$W_1 \in \mathbb{R}^{H \times D}$ 和 $W_2 \in \mathbb{R}^{C \times H}$ 是两组可学习的参数。输入 $x$ 首先经过一个线性变换 $W_1$，然后通过一个非线性函数 $\max(0, \cdot)$，最后再经过另一个线性变换 $W_2$ 得到最终输出。这个非线性的 $\max(0, \cdot)$ 函数被称为激活函数（Activation Function）。我们可以持续地进行这种堆叠，例如三层网络可以写为 $f = W_3 \max(0, W_2 \max(0, W_1 x))$，其中 $W_1 \in \mathbb{R}^{H_1 \times D}, W_2 \in \mathbb{R}^{H_2 \times H_1}, W_3 \in \mathbb{R}^{C \times H_2}$，以此类推，我们可以构建更深的网络。在实际应用中，每个线性层通常还会添加一个可学习的偏置项（Bias），例如 `f = Wx + b`。需要强调的是，“神经网络”是一个非常宽泛的术语，我们这里讨论的基础结构，更准确的叫法是**全连接网络（Fully-Connected Network）**或**多层感知机（MLP）**。

#### 为什么需要激活函数

激活函数在神经网络中扮演着至关重要的角色。一个很自然的问题是：如果我们把上述两层网络中的激活函数去掉，会发生什么？网络将变成 $f = W_2(W_1 x) = (W_2 W_1) x$。由于矩阵乘法的结合律，$W_2 W_1$ 可以等效为一个新的矩阵 $W_3$，于是 $f = W_3 x$。这意味着多个线性层的堆叠，其复合函数仍然是线性的，等价于一个单一的线性分类器。这将极大地限制模型的表达能力，使其无法学习数据中的非线性关系。

现实世界中的数据分布往往不是线性可分的。想象一个二维平面上红蓝相间的点，可能需要一个圆形边界才能把它们分开，而任何一条直线都无法完成这个任务。通过一个恰当的非线性特征变换，例如从笛卡尔坐标 $(x, y)$ 映射到极坐标 $(r, \theta)$，我们可以将原本非线性可分的数据变换到一个新的特征空间，使得它们可以用一个线性分类器轻松分离。神经网络中的激活函数，其本质上就是在执行这样一种非线性特征变换。它们将输入空间不断扭曲、映射，使得原本复杂的数据分布在最后几层变得线性可分。一个深层网络在做的，是将一个复杂的非线性映射，拆解成许多小段的、近似的线性变换，然后通过堆叠这些简单变换来拟合复杂的函数。

#### 常见的激活函数

对常见的激活函数，其公式和特性需要非常熟悉，达到可以立刻反应出来的程度。

| 激活函数 | 数学表达式 | 特点与局限 |
| :--- | :--- | :--- |
| **Sigmoid** | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 将输入压缩到 $(0, 1)$ 区间，曾广泛使用。其缺点是当输入 $x$ 的绝对值很大时，函数值趋近于0或1，导数会趋近于0，导致**梯度消失（Vanishing Gradient）**问题，严重阻碍网络训练。 |
| **Tanh** | $\tanh(x)$ | 将输入压缩到 $(-1, 1)$ 区间。同样存在饱和区，会导致梯度消失。 |
| **ReLU**| $f(x) = \max(0, x)$ | 目前应用最广泛的激活函数。当 $x>0$ 时，梯度恒为1，有效缓解了正半轴的梯度消失；当 $x<0$ 时，输出和梯度均为0。其非线性来源于在 $x=0$ 处的折断。计算非常简单，只需判断阈值。 |
| **Leaky ReLU** | $f(x) = \max(0.1x, x)$ | 为缓解ReLU在 $x<0$ 时梯度恒为0导致的“神经元死亡”问题而提出。通过在负半轴引入一个非常小的斜率（例如0.1），使得负值区域也能存在一个非零的梯度，保留了部分信息。 |
| **ELU** | $f(x) = \begin{cases} x, & x \ge 0 \\ \alpha(e^x - 1), & x < 0 \end{cases}$ | 类似于Leaky ReLU，旨在解决“神经元死亡”问题，并使激活函数的输出均值更接近于零，有助于加速训练。 |
| **Maxout** | $\max(w_1^T x + b_1, w_2^T x + b_2)$ | 这是一种更通用的形式，ReLU和Leaky ReLU都可看作其特例。它通过取两组线性输出中的最大值来引入非线性。 |

#### 神经网络的结构与参数规模

一个典型的神经网络架构是由输入层（Input Layer）、若干隐藏层（Hidden Layer）和输出层（Output Layer）组成的全连接层堆叠。在每一层隐藏层后，都会紧跟一个激活函数以引入非线性。全连接层的含义是，当前层的每一个神经元（Neuron）都与前一层的所有神经元存在连接。例如，一个输入维度和隐藏层维度均为 $10^6$ 的网络，仅是两层之间的权重矩阵 $W$ 就包含 $10^{12}$ 个参数。假设每个参数以32位浮点数（4 Bytes）存储，仅存储这些参数就需要约 $4TB$ 的内存，这还没有计算前向和反向传播所需的中间变量和梯度存储。这在计算和存储上都是灾难性的。

尽管存在参数爆炸的问题，全连接层依然没有被淘汰。在现代卷积神经网络（如ResNet）中，全连接层常被用在网络的最后几层，用于整合卷积层提取到的所有特征，并最终完成分类或回归等任务。此时，输入到全连接层的特征图（Feature Map）的空间维度（$H \times W$）通常已经过多次下采样变得很小，因此总的参数量是可控的。

通过一个极简的、使用Numpy编写的两层网络代码，可以更直观地理解神经网络的结构。我们定义网络大小、随机初始化数据和权重参数。训练循环主要分为三步：
1.  **前向传播（Forward Pass）**：计算 $h = \sigma(X \cdot W_1)$，得到隐藏层激活值；再计算预测值 $y_{\text{pred}} = h \cdot W_2$。
2.  **计算损失（Loss Computation）**：例如使用均方误差 $\text{loss} = \sum (y_{\text{pred}} - y_{\text{true}})^2$。
3.  **反向传播与参数更新**：手动计算损失关于 $W_1$ 和 $W_2$ 的解析梯度，再利用梯度下降法更新权重，更新公式为 $W \leftarrow W - \eta \cdot \nabla_W L$，其中 $\eta$ 是学习率。

通过设置更多的隐藏层或更宽的隐藏层（即更多神经元），我们可以增大模型的参数量，从而提升模型的容量（Capacity）和拟合能力。但是，仅仅追求更强的拟合能力是不对的。当模型层数过多，参数远超任务所需时，它可能会过度学习训练数据中的噪声和细节，导致**过拟合（Overfitting）**。一个过拟合的模型在训练数据上表现完美，但在未见过的测试数据上泛化能力会很差。

从生物学角度看，神经网络的设计灵感来源于大脑的神经元结构。大脑中约有860亿个神经元，通过突触（Synapse）构成一个极其复杂的网络。一个简化的神经元模型是：接收来自其他神经元的信号（$x_i$），每个信号乘以一个权重（$w_i$）后进行累加（$\sum w_i x_i + b$），当这个累加值超过一定阈值时，神经元被激活，并通过激活函数（Activation Function）向下一个神经元传递信号。这与我们设计的数学模型非常相似。虽然当前最大的人工神经网络（数百亿甚至上千亿参数）相比人脑仍有差距，但两者在结构抽象上是相通的。值得注意的是，生物神经网络中的连接非常不规则且复杂，而人工神经网络为了计算效率，通常将神经元组织成规则的层次结构。理论上，我们也可以设计一个连接模式完全随机的神经网络，它可能也能工作，但其精度和效率的平衡会变得非常困难。

### 损失函数与正则化

一个神经网络本身只是定义了一个从输入到输出的函数映射 $s = f(x; W)$。要让它能够学习，我们还需要定义一个**损失函数（Loss Function）**，用于量化模型预测值与真实标签之间的差异。模型训练的目标就是找到一组最优的权重 $W$，使得在整个训练集上的平均损失最小。

一个完整的损失函数通常由两部分构成：
$$L(W) = \frac{1}{N} \sum_{i=1}^{N} L_i(f(x_i, W), y_i) + \lambda R(W)$$
前面的求和项是**数据损失（Data Loss）**，它衡量的是模型在训练数据上的预测准确度。例如，在多分类问题中，$L_i$ 可以是SVM损失（Hinge Loss） $\sum_{j \neq y_i} \max(0, s_j - s_{y_i} + 1)$，也可以是Softmax损失（交叉熵损失, Cross-Entropy Loss） $-\log(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}})$。这部分损失推动模型去尽可能地拟合训练数据。

后面的 $\lambda R(W)$ 是**正则化项（Regularization）**，它衡量的是模型本身的复杂度。$\lambda$ 是一个超参数，用于平衡数据损失和正则化损失之间的权重。

#### 正则化的原理与动机

正则化是防止模型过拟合的核心技术。它的哲学基础是**奥卡姆剃刀原则（Occam's Razor）**：在多个能同样好地解释观测数据的假设中，最简单的那个往往是最好的。当我们只使用数据损失来训练模型时，可能会存在多组不同的权重 $W$ 都能实现较低的误差。此时，正则化项就扮演了一个“偏好指示器”的角色，它引导模型选择更“简单”、更“平滑”的解。“简单”通常意味着权重值更小或更稀疏。

例如，假设我们有一个输入 $x = [1, 1, 1, 1]$，以及两组预测结果相同的权重: $w_1 = [1, 0, 0, 0]$ 和 $w_2 = [0.25, 0.25, 0.25, 0.25]$。两者的输出都是1。L2正则化倾向于选择哪个呢？L2正则化计算的是所有参数的平方和。$R(w_1) = 1^2 + 0^2 + 0^2 + 0^2 = 1$，而 $R(w_2) = 0.25^2 \times 4 = 0.25$。由于 $R(w_2)$ 更小，L2正则化会倾向于选择 $w_2$。这说明L2正则化偏好**分散、较小的权重**，它会驱使模型利用所有输入特征，而不是只依赖少数几个。如果使用L1正则化（计算绝对值之和），两者的损失都是1，因此在这个特例中L1正则化并无偏好。但在更一般情况下，L1正则化会倾向于产生**稀疏的权重**，即许多权重变为零，从而起到特征选择的作用。

这两种正则化方法各自也存在局限性：
-   **L1正则化**：其损失函数 $L_1(W) = \sum |w|$ 在 $w=0$ 处是不可导的，这会给基于梯度的优化带来困难。
-   **L2正则化**：其损失函数 $L_2(W) = \sum w^2$ 的梯度是 $2w$。当 $w$ 很大时，梯度也很大，可能导致**梯度爆炸**；当 $w$ 很小时，梯度也成比例减小，有助于稳定收敛。

除了L1和L2正则化，后续研究还发展出了更多防止过拟合的技术。例如**Dropout**，在每次训练迭代中，它会随机地将一部分神经元的激活值以一定的概率 $p$ 置为零，相当于随机“丢弃”了一部分神经元。这可以看作是在每次训练时，我们都在一个更“瘦”的、结构随机的子网络上进行学习，能有效防止特征间的协同适应，增强泛化能力。另一个关键技术是**Batch Normalization**，它通过对网络中间层的激活值进行归一化，使其分布稳定在0均值、1方差附近，不仅加速了训练，也起到了一定的正则化效果。

### 反向传播方法

确定了损失函数后，我们需要一个有效的算法来计算损失 $L$ 对网络所有参数 $W$ 的梯度 $\nabla_W L$，以便使用梯度下降法进行优化。**反向传播**就是用于高效计算这些梯度的核心算法，其数学基础是链式法则（Chain Rule）的递归应用。

#### 计算图与链式法则

我们可以将一个复杂的函数表示为一个**计算图**，图中的节点表示运算，边表示数据流向。例如，函数 $f(x, y, z) = (x + y) \cdot z$ 的计算图可以先计算 $q = x + y$，再计算 $f = q \cdot z$。

给定具体数值，例如 $x=-2, y=5, z=-4$，我们可按以下步骤进行前向计算和反向传播：
1.  **前向传播**：计算每个节点的值。
    -   $q = x + y = -2 + 5 = 3$
    -   $f = q \cdot z = 3 \cdot (-4) = -12$

2.  **反向传播**：从最终输出 $f$ 开始，计算 $f$ 关于各个中间变量和输入的梯度。
    -   初始化：$\frac{\partial f}{\partial f} = 1$。
    -   对于乘法门 $f = qz$：
        -   “上游梯度（Upstream Gradient）”是 $\frac{\partial f}{\partial f} = 1$。
        -   “局部梯度（Local Gradient）”：$\frac{\partial f}{\partial q} = z = -4$， $\frac{\partial f}{\partial z} = q = 3$。
        -   根据链式法则，$\frac{\partial f}{\partial q} = 1 \cdot (-4) = -4$， $\frac{\partial f}{\partial z} = 1 \cdot 3 = 3$。
    -   对于加法门 $q = x + y$：
        -   上游梯度是 $\frac{\partial f}{\partial q} = -4$。
        -   局部梯度：$\frac{\partial q}{\partial x} = 1, \frac{\partial q}{\partial y} = 1$。
        -   根据链式法则，$\frac{\partial f}{\partial x} = (-4) \cdot 1 = -4$， $\frac{\partial f}{\partial y} = (-4) \cdot 1 = -4$。

这个将上游梯度与本地梯度相乘并传递给下游的过程，就是反向传播的核心。在计算图中，加法门像是一个“梯度分发器”，它会把上游梯度原封不动地传递给所有输入。乘法门则像一个“梯度交换器”，它会将上游梯度乘以另一个输入的值，再传递给当前的输入。Max门则像一个“梯度路由器”，它将上游梯度无衰减地只传递给前向传播中取值最大的那个输入，其余输入的梯度为0。

#### Sigmoid函数的梯度

以一个更复杂的函数为例，它可以被看作是一个完整的Sigmoid激活函数：
$$\sigma(x) = \frac{1}{1 + e^{-(w_0 x_0 + w_1 x_1 + w_2)}}$$
尽管我们可以将这个函数分解成乘法、加法、指数、倒数等原子操作，并构建一个详细的计算图来逐步反向传播，但这会非常繁琐。实际上，Sigmoid函数有一个非常简洁的局部梯度表达式：
$$\frac{d\sigma(x)}{dx} = \sigma(x)(1 - \sigma(x))$$
这意味着，在反向传播中，如果上游梯度是 $G$，经过一个Sigmoid门后，传递给下游的梯度就是 $G \cdot y(1 - y)$，其中 $y$ 是此次前向传播中Sigmoid门的输出。这种将多个原子操作合并成一个“门”并推导出其简洁局部梯度的思想，是现代深度学习框架（如PyTorch）高效实现的基础。

#### 向量形式的反向传播

以上讨论的都是标量对求标量的情况。在实际的神经网络中，输入、输出和中间变量绝大多数是多维向量或张量。当输入 $x \in \mathbb{R}^N$ ，输出 $y \in \mathbb{R}^M$ 时，函数对输入的导数将扩展为一个 $M \times N$ 的雅可比矩阵（Jacobian Matrix）：
$$ \frac{\partial y}{\partial x} = \begin{pmatrix} \frac{\partial y_1}{\partial x_1} & \cdots & \frac{\partial y_1}{\partial x_N} \\ \vdots & \ddots & \vdots \\ \frac{\partial y_M}{\partial x_1} & \cdots & \frac{\partial y_M}{\partial x_N} \end{pmatrix} $$

矩阵中的每个元素 $\frac{\partial y_m}{\partial x_n}$ 描述了当输入的第 $n$ 个元素发生微小变化时，输出的第 $m$ 个元素会如何变化。尽管引入了矩阵，反向传播的链式法则思想不变：损失 $L$ （一个标量）对输入向量 $x$ 的梯度，等于上游梯度（$L$ 对输出 $y$ 的梯度，一个向量）乘以该运算的局部雅可比矩阵。

在实际的计算中，**永远不要显式地构造和存储这个巨大的雅可比矩阵**。例如，对于一个逐元素（element-wise）的ReLU操作 $f(x) = \max(0, x)$，它的雅可比矩阵是一个对角矩阵，且对角线上只有0和1。有一种更高效的方法来隐式地完成乘法：我们只需要根据前向传播时 $x$ 的值，将上游梯度中对应 $x \le 0$ 的元素的梯度置0，其余保持不变即可。所以，在实现PyTorch这样的现代框架中，每个算子（operator）的C/C++底层代码都实现了高效的前向和经优化的向量化反向传播逻辑。

反向传播的模块化实现思路是：为每一个运算（如乘法、加法、sigmoid）定义一个“门”，这个门需要实现两个接口：
-   `forward(inputs)`：计算该运算的输出，并缓存（`save_for_backward`）任何在计算梯度时需要用到的中间变量（如输入值 `x`）。
-   `backward(upstream_grad)`：接收上游传来的梯度，并利用缓存的变量和局部梯度，计算出损失相对于该门所有输入的梯度。

框架会自动将用户定义的前向网络序列，构建成一个计算图。在反向传播时，它会逆序遍历这个图，依次调用每个门的 `backward` 接口，从而高效地完成全图所有参数的梯度计算。这就是为何我们如今可以专注于设计网络结构，而无需手动编写反向传播代码的原因。

### 优化方法

在得到所有参数的梯度 $\nabla_W L$ 后，我们就需要根据这些梯度来更新参数，这个过程被称为**优化（Optimization）**。优化的目标是逐步调整参数 $W$，使得损失函数的值不断减小，直至收敛到某个极小点。

#### 梯度下降法

最朴素的优化方法是**梯度下降法（Gradient Descent）**，其核心思想是让参数沿着梯度的反方向（即函数值下降最快的方向）移动一小步。更新公式为：
$$x_{t+1} = x_t - \alpha \nabla f(x_t)$$
其中，$\alpha$ 是**学习率（Learning Rate）**，也称为步长，是一个至关重要的超参数，决定了每次迭代参数更新的幅度。

#### 计算梯度的方式

计算梯度 $\nabla f(x)$ 有三种主要方式：
1.  **暴力随机搜索（Random Search）**：随机尝试大量参数组合，选择损失最低的。这种方法在参数空间巨大时效率极低，几乎不可能找到最优解。
2.  **数值梯度（Numerical Gradient）**：使用导数的定义，通过给参数 $x$ 的每个分量加上一个极小的扰动 $h$，计算 $\frac{f(x + h) - f(x)}{h}$ 来近似梯度。此方法非常简单且不容易出错，常被用来进行**梯度检查（Gradient Check）**，即验证我们推导的解析梯度是否正确。但它的缺点是速度极其缓慢，因为它需要对每个参数分别进行前向计算。
3.  **解析梯度（Analytic Gradient）**：就是我们通过反向传播算法和链式法则精确求得的梯度。这种方法精确、快速，但推导和实现容易出错。在工程实践中，我们始终使用解析梯度进行训练，但会利用数值梯度来进行正确性检查。

#### 梯度下降的变体

根据每次更新参数时所使用的数据量，梯度下降有三种形式：
-   **批量梯度下降（BGD）**：使用整个训练集来计算一次平均梯度并进行单步更新。梯度估计最为准确，但每走一步的计算代价和时间代价都极其高昂，尤其在大数据集上不现实。
-   **随机梯度下降（SGD）**：每次只随机使用一个样本来计算梯度并进行更新。更新非常频繁且计算单次梯度很快，但梯度估计的噪声巨大，导致损失函数的下降过程非常震荡，模型可能很难精确收敛。
-   **小批量随机梯度下降（Mini-batch SGD）**：这是目前深度学习中最常用的折中方案。每次从训练集中随机采样一小批（Minibatch，例如32/64/128个）样本，计算它们的平均梯度来更新参数。这样既比BGD单步计算更快，又比SGD的梯度估计更稳定。大部分情况下提到的SGD，实际指的都是Mini-batch SGD。

Mini-batch SGD使用小批量数据来近似整个训练集的真实梯度。由于每次抽取的批量数据未必能完美代表整体数据分布，因此我们计算出的梯度是一个有噪声的估计。这种噪声在某些情况下反而有益，因为它可能帮助优化轨迹跳出局部最小值或鞍点，但也会导致收敛过程震荡。

#### 梯度下降的挑战与改进

SGD的训练面临许多挑战：
-   **病态条件（Poor Conditioning）**：当损失函数在不同方向上的陡峭程度差异巨大时，梯度下降会表现出在陡峭方向剧烈震荡，而在平坦方向进展缓慢的“锯齿形”路径。这会导致收敛极慢。
-   **局部最小值与鞍点（Local Minima & Saddle Point）**：梯度为零的点不一定是全局最小值，它可能是局部极小值，更常见的是**鞍点**。鞍点在一些方向是极小值，在另一些方向却是极大值。经典的SGD在这些梯度为零的点上会停滞，无法被困住。

为了克服这些问题，研究者提出了一系列改进的优化器：

**1. SGD + Momentum（动量法）**
其灵感来源于物理学中的“惯性”。通过对历史梯度进行指数加权移动平均，来构建一个“速度”变量 $v$。参数更新不再只依赖于当前梯度，而是沿着这个积累的速度方向移动。
公式为：
$$v_{t+1} = \rho v_t + \nabla f(x_t)$$
$$x_{t+1} = x_t - \alpha v_{t+1}$$
其中，$\rho$ 是动量系数（通常设为0.9或0.99），它控制着历史梯度对当前速度的贡献程度。动量法的优势在于：当连续多步的梯度方向一致时，它可以加速下降；当遇到震荡或梯度突变时，它可以平滑路径；当遇到梯度为零的鞍点时，由于历史速度 $v_t$ 不为零，它可以凭借“惯性”冲过去，而不是停滞。

**2. RMSProp**
其核心思想是“自适应学习率”。它通过计算梯度平方的指数加权移动平均 $v$，来调整每个参数的学习率。对于频繁变动、梯度大的参数，用大学习率除以一个较大的数，从而降低其学习率，抑制震荡；对于梯度小的参数，则做相反的操作，加速其在平坦方向的进展。
公式为：
$$v_{t+1} = \beta v_t + (1 - \beta)(\nabla f(x_t))^2$$
$$x_{t+1} = x_t - \frac{\alpha}{\sqrt{v_{t+1}} + \epsilon} \nabla f(x_t)$$
其中的 $\epsilon$（例如 $10^{-7}$）是一个极小的常数，用于防止分母为零。

**3. Adam**
Adam是目前最流行、最常用的优化器之一，它将Momentum和RMSProp的思想结合了起来。它同时计算梯度的**一阶矩（均值）** $m_t$ 和**二阶矩（未中心化的方差）** $v_t$ 的指数移动平均，并对其进行偏差校正，以得到梯度的自适应学习率。
其更新流程大致为：
$m_t = \beta_1 m_{t-1} + (1 - \beta_1) \nabla f(x_t)$ （动量项）
$v_t = \beta_2 v_{t-1} + (1 - \beta_2) (\nabla f(x_t))^2$ （自适应学习率项）
然后分别对 $m_t$ 和 $v_t$ 做偏差修正，最后 $x_{t+1} = x_t - \alpha \frac{m_t}{\sqrt{v_t} + \epsilon}$。
Adam结合了动量法的加速和稳定收敛能力，以及RMSProp在不同维度上自适应调整学习率的能力，在绝大多数任务上表现出色，收敛速度快，调参相对简单。

#### 学习率调度

除了选择合适的优化器，学习率 $\alpha$ 本身的设置也至关重要。一个固定的学习率往往不是最优的。
-   **学习率过高**：会导致参数更新步幅过大，在最优点附近剧烈震荡甚至发散，无法收敛。
-   **学习率过低**：导数收敛速度极慢，训练时间过长，且容易陷入局部极小值。

因此，在实践中我们通常会采用**学习率调度（Learning Rate Schedules）**策略，让学习率随着训练过程的进行而动态衰减。常见的策略有：
-   **阶梯式衰减（Step Decay）**：在预设的若干轮次（Epoch）后，将学习率乘以一个衰减因子（如0.1）。
-   **余弦退火（Cosine Annealing）**：$\alpha_t = \frac{1}{2} \alpha_0 (1 + \cos(\frac{t\pi}{T}))$，学习率以余弦函数的形式从初始值平滑减小到0。
-   **线性衰减（Linear Decay）**：$\alpha_t = \alpha_0 (1 - \frac{t}{T})$。
-   **倒数平方根衰减（Inverse Sqrt Decay）**：$\alpha_t = \alpha_0 / \sqrt{t}$，在初始期学习率很大，能快速探索，随后随着时间下降进行精细优化。

此外，还有一种学习率预热（Warmup）技术，即在训练的初始几千次迭代中，将学习率从一个极小值线性增加到预设的初始值。这可以防止在训练初期，由于参数是随机初始化的，一个过大的学习率导致模型训练不稳定甚至发散。

### 卷积神经网络引言

全连接神经网络在面对图像数据时，会遭遇两个根本性问题：
1.  **参数爆炸**：对于一张 $1000 \times 1000 \times 3$ 的彩色图片，将其拉平为一个 $3 \times 10^6$ 维的向量作为输入。如果第一个隐藏层维度也是 $10^6$，那么仅这两层之间的权重矩阵就包含 $10^{12}$ 个参数。计算和存储都是灾难性的。
2.  **忽略空间结构**：全连接层将图像像素视为独立的、无序的变量，完全抛弃了像素点在二维空间中的邻域关系。而图像的局部性（附近像素高度相关，构成边缘、纹理等）是非常重要的先验知识。

为了解决这些问题，我们需要开发一种专门为图像设计的网络结构，即**卷积神经网络（Convolutional Neural Networks, CNNs）**。CNNs的设计利用了图像的两个核心特性：
-   **局部性**：一个像素点只与其周围局部邻域内的像素点强相关。
-   **平移不变性**：一个视觉模式（如一只鸟的喙），其在图片中的语义信息，不应因其出现在左上角还是右下角而改变。用于提取该模式的滤波器（卷积核），应该在整张图上共享。

CNNs通过**卷积层**来具体实现这两个特性。卷积层摒弃了全连接模式，每个神经元只与输入特征图的一个局部区域（称为感受野）相连。这个局部区域的大小和连接方式由一个小的权重矩阵决定，这个矩阵被称为**卷积核**。一个卷积核在整个输入特征图上以滑动窗口的方式遍历，每次与对应的局部区域做逐元素相乘并求和，这个操作也符合信号处理中的“互相关（cross-correlation）”计算。因为同一卷积核在空间所有位置被重用（参数共享），它提取的是一种空间上一致的特征（如一种特定纹理），这自然而然地赋予了网络平移不变性。CNNs也常配合池化层使用，以增大感受野并提供一定的缩放不变性。关于卷积神经网络的具体操作和结构细节，将在下一节课继续深入讲解。
