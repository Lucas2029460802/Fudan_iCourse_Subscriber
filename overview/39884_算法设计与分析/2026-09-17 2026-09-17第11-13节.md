### 快速排序的最坏情况与平均情况

快速排序的核心在于**划分（Partition）** 子算法。给定输入数组 $A[l..r]$，Partition 选择一个区分点（枢纽元素），将数组原地划分为两部分：左侧元素均不大于区分点，右侧元素均不小于区分点。划分完成后，区分点恰好落在其最终排序位置 $x$，随后递归地对 $A[l..x-1]$ 和 $A[x+1..r]$ 排序。与归并排序不同，快速排序在划分阶段已经确定了区分点的最终位置，因此**不需要显式的合并阶段**。

Partition 子算法的具体实现为：取 $x \leftarrow A[p]$ 作为枢纽，维护指针 $i$，从 $i=p$ 开始扫描 $j=p+1$ 到 $q$。每当遇到 $A[j] \le x$，就递增 $i$ 并交换 $A[i]$ 与 $A[j]$。扫描结束后交换 $A[i]$ 与 $A[p]$，返回枢纽最终位置 $i$。该过程需要遍历所有元素，因此对于长度为 $n$ 的输入，Partition 的复杂度为 $\Theta(n)$。

**最坏情况分析**：当输入数组已经有序或逆序时，若每次选取的区分点都是当前子数组的最小或最大元素，则划分后一侧子数组为空，另一侧只减少一个元素。此时递归式退化为 $T(n) = T(n-1) + \Theta(n)$。展开后得到 $T(n) = cn + c(n-1) + c(n-2) + \cdots + c + \Theta(1)$，结果为 $c \cdot \frac{n(n+1)}{2} + \Theta(1)$，即 $\Theta(n^2)$。递归树表现为一条线性链，每层只产生一个非平凡子问题。

**平均情况分析**：平均情况下枢纽在排好序的位置可以是第 $1$ 到第 $n$ 个位置中的任意一个，共 $n$ 种等可能的输入。若枢纽处于第 $i$ 个位置，则左侧子问题规模为 $i-1$，右侧为 $n-i$。将全部 $n$ 种可能性等概率叠加，得到递归式 $T(n) = \frac{2}{n}\sum_{i=1}^{n-1}T(i) + \Theta(n)$，其中 $T(1)=0$。这个含求和号的递归式无法直接通过递归树展开，需要利用**两方程相减**的消去技巧。将原方程乘以 $n$ 得到 $nT(n) = 2\sum_{i=1}^{n-1}T(i) + cn^2$，再将 $n$ 替换为 $n-1$ 得到 $(n-1)T(n-1) = 2\sum_{i=1}^{n-2}T(i) + c(n-1)^2$。两式相减消去求和符号，化简得到 $nT(n) = (n+1)T(n-1) + 2cn - c$。两边同时除以 $n(n+1)$ 并反复迭代，可求得 $\frac{T(n)}{n+1} = \Theta(\log n)$，从而 $T(n) = \Theta(n \log n)$。

### 从递归到分治思想

快速排序和归并排序共同揭示了一个重要性质：它们之所以可以用递归快速求解，关键在于**拆分后子问题与原问题保持相同的结构**。快速排序将 $n$ 个元素的排序问题分解为左侧 $k$ 个元素和右侧 $n-k-1$ 个元素的两个子排序问题；归并排序将原数组从中间一分为二，分别对两半递归排序后再合并。拆分本身不是目的，而是通过不断递归地在更小规模上重复同一个问题，最终将代价分摊至对数级层数。

由此可以形式化**分治算法**的三个阶段。以快速排序为例，**分解（Divide）** 阶段通过 Partition 将数组按区分点划分；**求解（Conquer）** 阶段递归地对左右子数组排序；**合并（Combine）** 阶段几乎无需额外工作，因为区分点已就位。归并排序则恰好相反：分解只需从中间切开，复杂度极低；但合并阶段需要通过 Merge 将两个有序子数组合并为完整有序数组，承担核心工作量。这一点说明，同样是分治算法，工作重心可以落在不同阶段。

分治法的通用模板是：如果问题 $P$ 足够小，则直接求解；否则将 $P$ 分成若干子问题 $P_1, P_2, \ldots, P_a$，对每个子问题递归调用同一过程，最后合并各子问题的解。识别一个分治算法需要检查三个关键点：**子问题是否比原问题更小**，**子问题是否保持同样的结构**，以及**子问题的解如何组合**。边界条件决定了递归何时停止。

需要注意，**递归是实现方式，分治是设计思想**。阶乘函数 $n! = n \cdot (n-1)!$ 虽然使用了递归，但每次只产生一个规模为 $n-1$ 的子问题，并未通过均匀拆分来降低复杂度，因此通常不称为分治算法。典型的分治递归应产生多个结构相同的子问题，如 $T(n) = T(k) + T(n-k-1) + O(n)$ 这类形式。进一步而言，把问题拆小不必然带来加速。效率取决于拆分后的形态：拆成多少个子问题、每个子问题有多大、分与合本身的开销有多贵。这些都是设计分治算法时需要首先思考的问题。

### 比较排序的下界

此前学习的插入排序、归并排序、快速排序、堆排序都属于**比较排序**，它们仅通过元素间的比较来获取顺序信息。其中表现最好的归并排序和堆排序在最坏情况下达到 $O(n \log n)$。一个自然的问题是：$O(n \log n)$ 是否就是比较排序算法的最优复杂度？是否存在更快的比较排序算法？

可以通过**决策树模型**来分析。对于 $n$ 个元素的排序问题，每次比较可以看作决策树中的一个内部节点。节点 $i:j$ 表示比较第 $i$ 号元素和第 $j$ 号元素；若 $a_i \le a_j$ 进入左子树，否则进入右子树。每个叶子节点对应一种最终的排列。算法在某次输入上的执行路径长度，就是从根节点行走到相应叶子的比较次数。因此，最坏情况下的运行时间即为决策树的高度。

对于 $n$ 个互不相同的元素，共有 $n!$ 种可能的排列，决策树必须拥有至少 $n!$ 个叶子节点来区分所有这些排列。另一方面，高度为 $h$ 的二叉决策树最多拥有 $2^h$ 个叶子节点。因此 $n! \le 2^h$，取对数得 $h \ge \log(n!)$。利用斯特林（Stirling）近似公式 $n! \approx \sqrt{2\pi n}(n/e)^n$，可得 $h \ge n \log n - n \log e = \Omega(n \log n)$。这证明了任何比较排序算法在最坏情况下都需要 $\Omega(n \log n)$ 次比较。这是一个根本性的下界，不可能被“更聪明的比较技巧”突破。

该下界成立需要三个前提：算法仅通过元素比较来获得顺序信息；需要处理任意互不相同的元素；考察的是最坏情况下的比较次数。非比较排序算法之所以能够突破该下界，是因为它们放弃了纯比较模型，转而利用输入数据的额外结构信息。典型的例子是**计数排序**。当输入数组 $A[i]$ 的取值范围已知且不大（$0 \le A[i] \le k$）时，可以直接统计每个键值出现的次数，然后按序输出。计数排序的时间复杂度为 $T(n,k) = O(n+k)$，空间复杂度为 $S(n,k) = O(k)$。它依靠对输入分布的额外假设来获得比 $\Omega(n \log n)$ 更快的排序速度。

算法下界的意义在于：上界给出可能性的保证，下界揭示理论上的极限。在设计算法时，不仅要分析“我的算法能跑多快”，也要清醒地认识到“在给定条件下任何算法都不可能快于某个界限”。

### 大模型推理优化的实例

分治思想在现代人工智能系统中有直接的应用，一个重要的例子是 $2023$ 年发表于 ICML 的 **Speculative Decoding（投机解码）**。大语言模型采用自回归解码方式，每个新 token 都必须依赖前面已生成的前缀，模型的每次前向计算只能生成一个 token。如果生成 $100$ 个 token，就需要约 $100$ 次昂贵的模型前向计算。单次前向计算在硬件和算子层面已经被高度优化，很难再进一步提升。能否让昂贵的模型**少调用几次**？

Speculative Decoding 的抽象模型是：输出之间存在依赖链 $F(x_1) \to x_2$，$F(x_1,x_2) \to x_3$，其中 $F$ 是昂贵的操作，且必须串行执行。其核心思想是**先猜再验证**：先使用一个便宜的小模型（Draft Model）连续生成多个候选 token，然后将这些候选 token 一次性送入大模型（Target Model），利用大模型的一次前向计算批量验证所有候选位置的正确性。

其实现依赖于 **因果掩码（Causal Mask）** 机制。在 Transformer 中，每个位置只能利用其左侧已出现的 token。如果候选 token 是 $y_1, y_2, y_3, y_4$，可以将完整序列 $[x_1,..,x_t, y_1, y_2, y_3, y_4]$ 一次输入目标模型，在一次前向计算中获得 $P(y_1|x_{1:t})$、$P(y_2|x_{1:t},y_1)$、$P(y_3|x_{1:t},y_1,y_2)$、$P(y_4|x_{1:t},y_1,y_2,y_3)$ 四个条件概率。四个位置可以同时计算，但每个位置只允许看到自己的左侧前缀。验证时仍需按从左到右的顺序进行接受或拒绝：如果 $y_1$ 通过则保留，若某个 $y_3$ 被拒绝，则其之后的 $y_4$ 条件前缀已经失效，不能直接采用，需从 $y_3$ 处重新开始推理。

该算法将原本 $4$ 次串行昂贵前向计算压缩为 $1$ 次批量验证。其加速效果来自于降低端到端耗时和昂贵串行调用的次数，而生成成本仍随输出长度增长。从算法思想的角度看，Speculative Decoding 展示了四个关键策略：**识别瓶颈**，找到真正昂贵的操作；**廉价推测**，用便宜方法提前预测；**批量验证**，把多个验证合并到一次昂贵计算中；**保持正确性**，加速过程必须满足原算法的正确性要求。它借助分治中“分解—批量处理—合并验证”的思路，以轻量计算减少重量计算的调用次数，是算法思想在深度学习推理优化中的典型案例。

### 求解递归式的方法

递归式是分析递归算法时间复杂度的通用工具。求解递归式主要有以下几种方法。

**递归树法**是直观的展开方式。以 $T(n) = T(n-1) + n - 1$，$T(1)=0$ 为例，可以不断展开：$T(n) = (T(n-2) + n-2) + n-1 = \cdots = T(1) + 1 + 2 + \cdots + n-1 = \frac{n(n-1)}{2}$。这种逐步代入的方式与递归树的逐层展开在数学上等价。

**代入法**包括直接代入和换元代入两种。直接代入即将右端的递归项不断展开直至边界条件，适合形如 $T(n) = T(n-1) + f(n)$ 的递归式。换元代入则适用于具有幂次结构的递归式，如 $T(n) = 2T(n/2) + n - 1$，$T(1)=0$。设 $n = 2^k$，则将递归式改写为 $T(2^k) = 2T(2^{k-1}) + 2^k - 1$，代入 $k$ 次后得到 $T(2^k) = 2^kT(1) + \sum_{i=0}^{k-1}2^i(2^{k-i}-1) = k2^k - 2^k + 1$，再代回 $k = \log n$ 得 $T(n) = n \log n - n + 1$。

**假设验证法**的思路是先猜测复杂度的阶，再代入原递归式验证。以平均情况快速排序的递归式 $T(n) = \frac{2}{n}\sum_{i=1}^{n-1}T(i) + \Theta(n)$ 为例（设 $\Theta(n) = an$）。首先设 $T(n) = c$，代入后右边为 $2c - 2c/n + an$，不可能恒等于常数 $c$，验证失败。其次设 $T(n) = cn$，代入后右边化简为 $cn - c + an$，看似同阶，但等式成立要求 $c = an$，这依赖于特定的 $n$ 取值而非任意 $n$，因此验证不通过。再设 $T(n) = cn^2$，代入化简后为 $\frac{2c}{3}n^2 + O(n)$，最高阶系数 $\frac{2c}{3}$ 与左边的 $c$ 不匹配，也不通过。最后设 $T(n) = cn \log n$，利用阶乘与求和，将求和项展开后得到右边为 $cn \log n + O(n)$，最高阶系数一致，低阶项 $O(n)$ 严格低于 $n \log n$，可以被高阶项覆盖，因此验证通过，结论为 $T(n) = \Theta(n \log n)$。

假设验证法的判定可以总结为“三看”：一看**阶**，代回后主导增长阶是否一致；二看**系数**，同阶时最高阶项系数能否自洽；三看**低阶项**，若只判断渐近阶，严格低阶项可以忽略。这也是第一次课中用到的消项代入技巧的形式化表达。

**主定理**提供了一类递归式的通用解法。对于形如 $T(n) = aT(n/b) + f(n)$ 的递归式，其中 $a \ge 1$、$b > 1$ 为常数，$f(n)$ 为某函数，设 $n^{\log_b a}$ 为基准复杂度，则有三种情况。

**情况一**：若 $f(n) = O(n^{\log_b a - \epsilon})$（$\epsilon > 0$），即 $f(n)$ 的增长严格慢于 $n^{\log_b a}$ 一个多项式因子，则 $T(n) = \Theta(n^{\log_b a})$。**情况二**：若 $f(n) = \Theta(n^{\log_b a})$，即两者增长同阶，则 $T(n) = \Theta(n^{\log_b a} \log n)$。**情况三**：若 $f(n) = \Omega(n^{\log_b a + \epsilon})$（$\epsilon > 0$），且满足正则条件 $af(n/b) \le cf(n)$（$c<1$），则 $T(n) = \Theta(f(n))$。

主定理的推导可以通过展开 $n = b^k$ 来完成。将递归式逐层展开得 $T(n) = a^kT(1) + \sum_{j=0}^{k-1}a^j f(n/b^j)$。因为 $a^k = a^{\log_b n} = n^{\log_b a}$，所以 $T(n) = cn^{\log_b a} + \sum_{j=0}^{k-1}a^j f(n/b^j)$。将三种情况下 $f(n)$ 的边界条件代入求和式，即可分别得出对应的渐近界。主定理本质上是对递归树的层级求和的数学整理。

以 $T(n) = 4T(n/2) + n$ 为例：取 $a=4, b=2$，得 $n^{\log_b a} = n^2$。$f(n)=n$ 比 $n^2$ 慢，取 $\epsilon = 1$ 即满足情况一的条件 $f(n) = O(n^{2-1}) = O(n)$，因此 $T(n) = \Theta(n^2)$。若 $f(n) = n^2$，则满足情况二，$T(n) = \Theta(n^2 \log n)$。若 $f(n) = n^3$，则满足情况三，此时 $af(n/b) = 4(n/2)^3 = n^3/2 \le cn^3$，取 $c = 1/2 < 1$ 即可，因此 $T(n) = \Theta(n^3)$。

主定理并非万能。对于 $T(n) = 2T(n/2) + n \log n$，此时 $a=b=2$，$n^{\log_b a} = n$，而 $f(n) = n \log n$。不存在 $\epsilon > 0$ 使得 $n \log n = \Omega(n^{1+\epsilon})$，因为 $n^{\epsilon}$ 的增长快于 $\log n$；也不存在 $c<1$ 满足正则条件 $2f(n/2) = n\log n - n \le cn \log n$（当 $\log n$ 足够大时不成立）。三种情况均不满足，因此主定理不可用，需要借助递归树。将其展开后，第 $i$ 层的总代价为 $n(\log n - i)$，树高为 $\log n$，求和得 $T(n) = n\sum_{i=0}^{\log n -1}(\log n - i) + \Theta(n) = \Theta(n \log^2 n)$。

### 二分检索算法

二分检索针对排序好的数组 $T[l..r]$，搜索目标数 $x$。算法维护当前搜索区间 $[l,r]$，每轮比较中间元素 $T[m]$（$m = \lfloor(l+r)/2\rfloor$）与 $x$ 的大小：若相等则返回位置 $m$；若 $T[m] > x$ 则在左侧继续搜索，令 $r \leftarrow m-1$；否则在右侧搜索，令 $l \leftarrow m+1$。若区间为空仍未找到，则返回 $0$ 表示查找失败。

在最坏情况下，每比较一次搜索范围减半：$n \to n/2 \to n/4 \to \cdots \to 1$，因此比较次数为 $\log n$ 量级，复杂度为 $O(\log n)$。平均情况的分析需要枚举所有可能的输入。设数组长度为 $n = 2^k - 1$。若 $x$ 在数组中，则 $x$ 可能等于 $T[1], T[2], \ldots, T[n]$，共 $n$ 种输入；若 $x$ 不在数组中，则可能落在第一个元素之前、相邻两个元素之间或最后一个元素之后，共 $n+1$ 种区间。总共有 $2n+1$ 种输入情形。

对于比较次数的分布：数组正中间的元素只需比较 $1$ 次即可找到（$1$ 种输入）；位于左右半区正中间的两个元素需要比较 $2$ 次（$2$ 种输入）；更小规模的正中间元素共 $4$ 个需要比较 $3$ 次；一般地，有 $2^{t-1}$ 种输入需要比较 $t$ 次（$t = 1,2,\ldots,k-1$）。需要比较 $k$ 次的输入包括：在数组中但位于最末层搜索的元素，共 $2^{k-1}$ 种；以及全部 $n+1$ 种查找失败的情形（因为确定元素不存在必须将区间分割至空）。因此需要比较 $k$ 次的输入总数为 $2^{k-1} + n + 1$ 种。

在所有 $2n+1$ 种输入等概率的假设下，平均比较次数为 $T(n) = \frac{1}{2n+1}\left[\sum_{t=1}^{k-1}t \cdot 2^{t-1} + k(2^{k-1} + n + 1)\right]$。代入 $n = 2^k - 1$，化简后得到 $T(n) \approx k - \frac{1}{2}$，即 $\lceil\log n\rceil - \frac{1}{2}$。因此二分检索的平均情况复杂度为 $O(\log n)$，与最坏情况同阶。从分治视角看，二分检索属于“易分难合”的典型：分解只需在中间进行一次比较后选择左半或右半区间，合并阶段完全不需要任何额外工作。

### 分治应用于矩阵乘法：Strassen 算法

矩阵乘法的输入为两个 $n \times n$ 矩阵 $A$ 和 $B$，输出 $C = AB$，其中 $C_{ij} = \sum_{k=1}^{n}A_{ik}B_{kj}$。朴素算法使用三层嵌套循环，对每组 $i,j$ 求和 $k$，复杂度显然为 $\Theta(n^3)$。能否利用分治思想降低这一复杂度？

最直接的分治做法是将每个矩阵等分为四个 $n/2 \times n/2$ 的子矩阵：$A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$，$B = \begin{bmatrix} e & f \\ g & h \end{bmatrix}$。则 $C = \begin{bmatrix} r & s \\ t & u \end{bmatrix}$ 中，$r = ae + bg$，$s = af + bh$，$t = ce + dg$，$u = cf + dh$。这需要 **8 次** $n/2 \times n/2$ 的递归子矩阵乘法，以及 **4 次** 子矩阵加法。递归式为 $T(n) = 8T(n/2) + \Theta(n^2)$。应用主定理：$a=8, b=2$，$n^{\log_b a} = n^3$，而 $f(n) = \Theta(n^2)$ 满足情况一（$n^2 = O(n^{3-\epsilon})$，取 $\epsilon=1$），因此 $T(n) = \Theta(n^3)$。朴素分块的复杂度与暴力算法完全相同，没有产生任何渐近改进。

瓶颈显然在于 8 次递归乘法。想突破 $n^3$，必须减少乘法的次数。**Strassen 算法**的核心思想是用更多的加法/减法来替换掉一次递归乘法。其构造的 7 个中间乘积为：

$$M_1 = (A_{11} + A_{22})(B_{11} + B_{22}), \quad M_2 = (A_{21} + A_{22})B_{11}$$

$$M_3 = A_{11}(B_{12} - B_{22}), \quad M_4 = A_{22}(B_{21} - B_{11})$$

$$M_5 = (A_{11} + A_{12})B_{22}, \quad M_6 = (A_{21} - A_{11})(B_{11} + B_{12})$$

$$M_7 = (A_{12} - A_{22})(B_{21} + B_{22})$$

利用这 7 个乘积，通过 18 次加减法即可组装出结果：$C_{11} = M_1 + M_4 - M_5 + M_7$，$C_{12} = M_3 + M_5$，$C_{21} = M_2 + M_4$，$C_{22} = M_1 - M_2 + M_3 + M_6$。Strassen 的构造原理可以通过一个简化例子来理解。以计算 $r = ae + bg$ 为例，取 $M_1 = (a+d)(e+h) = ae + ah + de + dh$，$M_4 = d(g-e) = dg - de$，$M_5 = (a+b)h = ah + bh$，$M_7 = (b-d)(g+h) = bg + bh - dg - dh$。那么 $M_1 + M_4 - M_5 + M_7$ 中大量交叉项相互抵消，最终只留下 $ae + bg$。关键是认识到我们不需要逐个知道每个乘积的值，只需要最终得到 $r,s,t,u$ 即可。通过混合运算中多重信息的叠加和加减法消去，用 7 次乘法完成了原本 8 次乘法才能完成的任务。

Strassen 算法的递归式为 $T(n) = 7T(n/2) + 18n^2$，应用主定理得 $T(n) = \Theta(n^{\log 7}) \approx O(n^{2.81})$，成功将矩阵乘法的指数从 $3$ 降至约 $2.81$。这一思想在 AI 中极具价值，因为现代神经网络中的大量计算——全连接层、Transformer 中的 Q、K、V 投影以及注意力计算中的 $QK^T$ 和 $\text{softmax}(\cdot)V$——本质上都是矩阵乘法。矩阵乘法的效率直接影响模型训练和推理的速度。

### 分治应用于多项式乘法：Karatsuba 算法与 FFT

**Karatsuba 算法**是分治思想在多项式乘法上的经典应用，其核心同样是**用加法换乘法**。对于两个 $n-1$ 次多项式 $A(x)$ 和 $B(x)$，将其按系数对半拆分：$A(x) = A_0(x) + x^{n/2}A_1(x)$，$B(x) = B_0(x) + x^{n/2}B_1(x)$。直接分治需要计算 $A_0B_0$、$A_0B_1$、$A_1B_0$、$A_1B_1$ 共 4 个 $n/2$ 次多项式乘法。递归式 $T(n) = 4T(n/2) + O(n)$，主定理给出 $T(n) = \Theta(n^2)$，与暴力计算相同。

Karatsuba 算法巧妙地将两个交叉项合并计算：$A_0B_1 + A_1B_0 = (A_0 + A_1)(B_0 + B_1) - A_0B_0 - A_1B_1$。这样在已经计算 $A_0B_0$ 和 $A_1B_1$ 的基础上，只需要**额外一次**乘法即可得到交叉项，总乘法次数从 4 降到 3。递归式变为 $T(n) = 3T(n/2) + O(n)$，主定理得 $T(n) = \Theta(n^{\log 3}) \approx O(n^{1.584})$。Karatsuba 的思想与 Strassen 一脉相承：将两次乘法合并为一次，代价是增加若干次加减法运算。由于多项式加法的复杂度仅为 $O(n)$，远低于乘法的 $O(n^2)$，这种代换在渐近意义下显著降低了总体复杂度。

**快速傅里叶变换（FFT）** 则从更根本的层面加速了多项式乘法，将复杂度降至 $O(n \log n)$。其核心思路是利用**点值表示**来代替系数表示。$n$ 次多项式可以通过在 $n+1$ 个不同点上的取值唯一确定。两个多项式在相同点上的值可以直接对应相乘，因此点值表示下的多项式乘法只需要 $O(n)$ 次标量乘法。问题在于：从系数表示到点值表示的**求值**，以及从点值表示回到系数表示的**插值**，朴素的拉格朗日插值法需要 $O(n^2)$ 次运算。FFT 将这两步均优化到 $O(n \log n)$，总流程为：系数求值（FFT，$O(n\log n)$）→ 点值相乘（$O(n)$）→ 插值（逆 FFT，$O(n\log n)$），从而将整个多项式乘法优化至 $O(n \log n)$。

FFT 的分治拆分方式是将多项式按奇偶系数拆分为 $A(x) = A_{even}(x^2) + x A_{odd}(x^2)$。直接在每个点上递归计算 $A_{even}$ 和 $A_{odd}$ 的复杂度为 $T(n) = 2T(n/2) + O(1)$ 每点，总复杂度仍是 $O(n^2)$。关键在于减少递归调用的计算开销：若选择点成对出现（$\pm x_0, \pm x_1, \ldots$），则 $A(x_i)$ 和 $A(-x_i)$ 的计算可以共享 $A_{even}(x_i^2)$ 和 $A_{odd}(x_i^2)$ 的结果，仅多计算一次符号翻转。一次调用的代价即可获得两个对称点的函数值，将评估 $n$ 个点的问题降至在 $n/2$ 个点上评估两个 $n/2-1$ 次多项式。

但这一策略有一个隐藏要求：每层递归的点集平方后必须仍然形成正负对称对。普通的正负点集（如 $\{\pm 1, \pm 2\}$ 平方后变为 $\{1,1,4,4\}$）不满足这一要求。解决方案是使用**单位复数根** $W_n = e^{2\pi i/n}$，它是 $z^n=1$ 的解，满足 $\cos\theta + i\sin\theta$ 的欧拉形式。单位复数根具有**折半定理**：当 $n$ 为偶数时，$n$ 个 $n$ 次单位复数根的平方的集合恰好是 $n/2$ 个 $n/2$ 次单位复数根的集合。以 $w_4$ 为例：$w_4 = i$，四个根为 $1, i, -1, -i$，平方后变为 $1, -1, 1, -1$，去重后为 $1, -1$，即 $w_2$。每一层平方后点数减半，且剩余点集依旧满足正负对称，从而保证递归可以在每一层持续进行。

基于单位根的 FFT 算法递归式在每轮合并时只需执行一次蝶形运算，复用一次对称点的计算结果，其递归式为 $T(n) = 2T(n/2) + O(n)$，解得 $T(n) = O(n \log n)$。FFT 的核心思想在于用单位根及其折半性质构造递归结构，使分治的每一层都最大化信息复用，将求值和插值的复杂度同时压缩到对数线性级别。
